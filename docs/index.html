How it works

Three steps, none of them cloud-based

Lostop doesn't change how you type — it just stands between your input field and the network.

01

Type as usual

Lostop watches the input field on the page — not your screen, not your clipboard, just what you actually type into the chat.

02

Local check

The moment you hit send, the text is checked against known leak patterns right on your machine — not a single character leaves for the check itself.

03

Pass or block

Clean, and the message goes through as usual. A secret is found, and the request is stopped — you see exactly what triggered the block.

Install

Ready in 5 minutes

Chrome won't let a third-party site install extensions with one click — that's a safeguard, not our choice. Still, the whole process fits into four clear steps.

  1. Download the extension

    Click the button below — a ZIP file downloads. Unzip it anywhere convenient.

  2. Load it into Chrome

    Open chrome://extensions, turn on Developer mode, click Load unpacked, and select the extension folder.

  3. Start the local checker

    Lostop checks text against a local server on your machine — start it with one command from the backend folder.

  4. Done

    Open ChatGPT, Claude, or DeepL — Lostop is already watching the input field, nothing else to turn on.
